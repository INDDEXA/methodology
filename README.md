# INDDEXA Public Methodology

This repository holds publication-ready, plain-Markdown copies of INDDEXA's **public research methodology**. It exists so that readers, researchers and third parties can cite, diff and archive the method independently of the website.

**The website is canonical.** These files are a faithful mirror of the published versions. If anything here differs from the live site, the live site governs.

## Version history

- **V1.0** — published 2026-11-17, last updated 2026-11-19. Expanded the public methodology from a short outline into a complete research-method statement, aligned with INDDEXA's internal method set. Internal scoring thresholds remain unpublished.
- **V1.1** — published 2026-11-22. A revision of V1.0: clarifies wording and adds method examples and public-facing explanation, with an updated version history. It adds no public section, changes no public commitment, and alters no criterion or value. Internal scoring thresholds remain unpublished.

See `CHANGELOG.md` for the itemised differences.

## Scope note

This repository contains the **public** methodology only. It deliberately excludes internal working scores, thresholds, grading labels and other internal control identifiers. It is not an external industry standard and does not replace professional or legal standards that may apply to a source we cite.
